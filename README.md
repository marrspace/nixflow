# Nixflow - Cloud Hosting & Pterodactyl Automation Panel

High-End Web Application untuk pengelolaan server Pterodactyl, topup saldo NX, pembuatan akun admin reseller, dan otomasi provisioning.

## Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS (Modern Obsidian Glassmorphism)
- **Icons:** Lucide React
- **Deployment:** Vercel Ready

## Cara Deploy ke Vercel

1. Hubungkan repository GitHub ini di dashboard [Vercel](https://vercel.com).
2. **Framework Preset:** `Vite`
3. **Build Command:** `npm run build`
4. **Output Directory:** `dist`
5. Klik **Deploy**!
